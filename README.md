# Rede Solidária de Apoio a Migrantes e Refugiados
Projeto acadêmico em Java e MySQL para modelar o recebimento, a organização e a destinação de doações para famílias migrantes e refugiadas.

## Etapa 2
- Modelagem orientada a objetos baseada no diagrama UML.
- Estrutura inicial das classes e enums Java.
- Script SQL para criação das tabelas relacionais.
- Separação inicial entre model, services e repository.
- Documento com a arquitetura inicial.

## Tecnologias
- Java
- MySQL

## Pastas
- `src/com/RedeSolidaria/model`: classes do domínio.
- `src/com/RedeSolidaria/services`: serviços da ONG.
- `src/com/RedeSolidaria/repository`: futura camada de persistência.
- `sql/schema.sql`: criação do banco.
- `docs/arquitetura.md`: arquitetura.

A integração efetiva com MySQL e as regras completas de estoque, reserva e distribuição serão desenvolvidas nas próximas etapas.
